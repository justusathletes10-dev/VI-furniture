# VI Furniture Store — Brand Intro

A 10-second cinematic brand intro for **VI Furniture Store** (Vietnamese luxury furniture e-commerce), built with [Remotion](https://www.remotion.dev/).

- **Duration:** 10 seconds (300 frames @ 30 fps)
- **Resolution:** 1920 x 1080
- **Composition id:** `ViBrandIntro`
- **Style:** Liquid Glass — translucent, smooth, elegant
- **Palette:** Primary `#2563EB`, Gold `#C9A96E`, Background `#F8FAFC`, Text `#1E293B`
- **Typography:** Cinzel (display) + Josefin Sans (body)

## Scenes

1. **0–2 s** — Animated VI monogram emerges with gold shimmer and soft blur reveal
2. **2–5 s** — Three product hero shots (sofa, dining table, bed) cross-fade with subtle Ken Burns zoom
3. **5–8 s** — Tagline animates in: *"Crafted for the Modern Vietnamese Home"*
4. **8–10 s** — Final logo + URL `vifurniturestore.com` with gold underline draw

## Setup

```bash
npm install
```

## Preview (Remotion Studio)

```bash
npm start
```

Opens the Remotion Studio at <http://localhost:3000>.

## Render

```bash
npm run build
```

Outputs `out/intro.mp4`.
